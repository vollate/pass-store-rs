# Pars

`Pars` is a cross platform [zx2c4-pass](https://www.passwordstore.org/) compatibility tool for managing password.

- [CLI documentation](cli/README.md)
- [GUI documentation](gui/README.md)
- [Core library documentation](core/README.md)

## GUI

The Flutter GUI in [`gui/`](gui/) provides a cross-platform graphical interface backed by `pars-core` via `flutter_rust_bridge`, supporting Android, iOS, macOS, Linux, and Windows. See [gui/README.md](gui/README.md) for features, prerequisites, native bridge build instructions, and development workflows.
